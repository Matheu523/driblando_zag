# driblando_zag
Você é um atacante que conduz a bola pelo campo enquanto os zagueiros adversários tentam desarmá-lo. Desvie, faça dribles para somar combos, colete moedas e, ao chegar na área, enfrente o goleiro na finalização. Entre as fases, use as moedas no Centro de Treinamento para evoluir seu jogador.
